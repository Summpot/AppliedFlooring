# Applied Flooring 地板纹理与 CTM 连接系统开发原理指南

本文档详细记录了 **Applied Flooring** 模组中 ME 地板（ME Flooring）、ME 电梯（ME Elevator）以及 ME 激光连接器（ME Laser Connector）的纹理几何划分、CTM 连接切片规范、周期拉普拉斯数学生成原理，以及后续修改纹理时的维护操作流程。

---

## 1. 系统架构概述

模组采用了对游戏原生零侵入、同时向下兼容两套成熟连接纹理模组的方案：

1. **Athena CTM 支持**：
   - 在 [`blockstates/<name>.json`](file:///c:/Users/Summp/source/repos/AppliedFlooring/common/src/main/resources/assets/appliedflooring/blockstates/) 中声明 `"athena:loader": "athena:ctm"`；
   - 依赖 4 款 16x16 伙伴切片文件：`_empty.png`, `_center.png`, `_h.png`, `_v.png`，以及基础贴图 `<name>.png`（作为 `particle`）；
   - 在方块状态中配置 `connect_to` 规则，使同色系的地板、电梯与激光连接器三者互相连通。

2. **Fusion CTM 支持**：
   - 在 [`assets/appliedflooring/fusion/model_modifiers/blocks/`](file:///c:/Users/Summp/source/repos/AppliedFlooring/common/src/main/resources/assets/appliedflooring/fusion/model_modifiers/blocks/) 中配置方块模型修改器，无缝重定向至 Fusion 模型；
   - 采用 Fusion 的 **Pieced** 规范（80x16 贴图），单张图片横向包含 5 个 16x16 切片槽位：`[base, empty, v_img, h_img, center]`；
   - 配套生成 `_online.png.mcmeta` 与 `_offline.png.mcmeta`，配置 `match_block` 实现同色系方块互连。

3. **原生兼容**：
   - 纯净客户端不安装任何 CTM 模组时，正常解析 BlockState 原版 `variants`，渲染单体独立方块模型，无紫黑错误。

## 2. 16x16 像素几何划分

每个 16x16 的基础方块贴图严格按照以下几何分区设计：

```text
       x = 0   1   2   3 ... 12  13  14  15
y = 0  +---+---+---+-----------+---+---+---+  <-- 外边框顶 (高光 ~74-78)
y = 1  |   +---+---+-----------+---+---+   |  <-- 内框架顶 (~66-70)
y = 2  |   |   +---+-----------+---+   |   |  <-- 倒角暗槽顶 (~61-64)
y = 3  |   |   |                   |   |   |
  :    |   |   |   中心金属面板     |   |   |
       |   |   |   (10x10 Plate)   |   |   |  <-- 基础面板/中心铆钉 (~66-70)
y = 12 |   |   |                   |   |   |
y = 13 |   |   +---+-----------+---+   |   |  <-- 倒角暗槽底 (~60-63)
y = 14 |   +---+---+-----------+---+---+   |  <-- 内框架底 (~66-70)
y = 15 +---+---+---+-----------+---+---+---+  <-- 外边框底 (阴影 ~56-60)
         ^   ^   ^               ^   ^   ^
         |   |   |               |   |   +-- 外边框右 (阴影 ~56-60)
         |   |   |               |   +------ 内框架右 (~66-70)
         |   |   |               +---------- 倒角暗槽右 (~60-65)
         |   |   +-------------------------- 倒角暗槽左 (~61-66)
         |   +------------------------------ 内框架左 (~66-70)
         +---------------------------------- 外边框左 (高光 ~74-77)
```

### 关键约束：
- **中心面板区域**：`x ∈ [3..12], y ∈ [3..12]`（10x10 像素），是无缝平铺的主要视觉基底。
- **功能图标范围**：电梯（箭头）与激光连接器（透镜）的图标**严格被限制在 `x ∈ [3..12], y ∈ [3..12]` 内部**。
- **100% 外围共享**：电梯与激光连接器在 `3..12` 以外的全部 156 个像素与同色普通地板完全相同。因此，只需将功能图标叠加到普通地板切片上，即可确保电梯、激光连接器与地板连接时边缘完全无缝。

## 4. 无缝生成的数学与几何原理

### 4.1 传统克隆边缘的缺陷
早期脚本采用简单复制相邻像素（如将 `x=1` 复制给 `x=0`，`x=14` 复制给 `x=15`），导致严重问题：
1. **边缘重复条纹**：拼接线两侧出现 2px 宽的平面条纹；
2. **色差断层**：方块 A 的右阴影边（~56-58）与方块 B 的左高光边（~74-76）在接缝处直接相遇，产生高达 **18** 个色彩单位的突兀跳变；
3. **凹槽残留凸棱**：第 2、13 行的倒角暗槽未被消除，导致连通方块交界处产生夹在两条暗槽中间的 4px 宽凸棱。

### 4.2 环面周期拉普拉斯插值算法 (Toroidal Laplace Interpolation)
为确保方块平铺时在接缝处没有任何断层，我们将 16x16 离散网格映射到二维环面拓扑 $T^2 = \mathbb{R}^2 / (16\mathbb{Z})^2$：
- 在环面上，$x=15$ 与 $x=0$ 天然相邻，$y=15$ 与 $y=0$ 天然相邻；
- 将中心 10x10 金属面板（`x, y ∈ [3..12]`）作为固定狄利克雷边界条件；
- 在外围未知区域（6 像素宽环形空隙，接缝 $15 \leftrightarrow 0$ 恰好位于正中央）求解离散拉普拉斯方程：
  $$\nabla^2 u(x, y) = u(x+1, y) + u(x-1, y) + u(x, y+1) + u(x, y-1) - 4u(x, y) = 0$$
- 采用 Jacobi 迭代法求解，保证基底亮度在周期环面上完全连续光滑过渡，接缝基底色差降为 0。

### 4.3 全局均衡低频周期噪声 (Balanced Periodic Noise)
如果在拉普拉斯插值区域不添加噪声，边缘会呈现不自然的模糊色块；若添加单像素高斯白噪声，高频抖动会导致沙砾密集感。因此采用周期低频滤波：
1. **环面高斯滤波**：
   在环面上生成标准正态分布随机数，并通过 `scipy.ndimage.gaussian_filter(..., sigma=0.5, mode='wrap')` 滤波。轻度滤除单像素高频尖锐分量，使噪点聚集成 1.5 ~ 2 像素尺度的微观拉丝质感。
2. **方差严格平衡**：
   重采样噪声标准差使其严格匹配中心面板的自然方差（$\sigma_{\text{std}} = \text{plate\_std} \approx 2.18$）。使方块边缘标准差（~2.37）与中心（~2.18）完全一致，杜绝“边缘过于平滑、噪点全挤在中心”的失衡视觉。
3. **色彩通道偏置保真**：
   AE2 金属面板遵循严格的单色噪点加恒定色偏法则：
   $$G(x, y) = R(x, y) + \Delta G, \quad B(x, y) = R(x, y) + \Delta B$$
   例如未染色材质中 $\Delta G = -6, \Delta B = +17$ 处处恒定。算法在 R 通道求解后直接平移到 G、B 通道，杜绝任何偏色伪影。

### 4.4 边框切片交叉伪影消除
在生成 `h_img` 与 `v_img` 时：
- `h_img` 是横向连通，但在原始 `base` 中第 1、2 行的两端包含竖向边框与拐角。算法将 `h_img` 第 1 行（框架）、第 2 行（凹槽）、第 13 行（凹槽）、第 14 行（框架）、第 15 行（底边）在两端平滑横向贯通，消除了横向拼接时两端出现的竖向边框突起；
- `v_img` 是纵向连通，同理消除上下两端的横向边框突起。

## 5. 后续调整与维护操作指南

### 5.1 极简维护架构：仅需维护 6 张主模板贴图
所有主模板贴图均位于：
`common/src/main/resources/assets/appliedflooring/textures/block/`

开发者**无需手动维护 16 种颜色的贴图，也无需手动绘制任何 CTM 切片**。只需编辑以下 6 张基础无色/原色贴图：
- 普通地板：`me_flooring.png`（在线态）、`me_flooring_offline.png`（离线态）
- 电梯方块：`me_elevator.png`（在线态）、`me_elevator_offline.png`（离线态）
- 激光连接器：`me_laser_connector.png`（在线态）、`me_laser_connector_offline.png`（离线态）

**设计约束**：
- 保持尺寸为 16x16 RGBA PNG；
- 电梯（箭头）与激光连接器（透镜）的功能图标严格保留在 `[3:13, 3:13]` 范围内部，以保证与普通地板的最佳无缝拼接效果。

### 5.2 运行自动化生成脚本
在项目根目录下执行：
```bash
python tools/textures/generate_ctm_textures.py
```
或通过 Gradle 任务执行：
```bash
./gradlew generateTextures
```

脚本将在 **1~2 秒内** 自动完成：
- 读取 6 张主模板贴图并求解环面周期拉普拉斯方程与均衡周期微观噪声；
- 应用 AE2 官方色彩偏置，自动衍生生成全部 16 种颜色的基础贴图（共 102 张）；
- 自动生成全部 204 张 Athena 16x16 CTM 切片贴图；
- 自动拼接生成全部 102 张 Fusion 80x16 贴图，并自动生成全部 102 份配套的 `.mcmeta` 互连规则配置文件。

#### 高级参数调节：
- `--sigma <float>`：控制噪点平滑滤波半径（默认 `0.5`）。若觉得噪点依然偏密，可调大至 `0.6` ~ `0.7`；若觉得边缘微糊，可调小至 `0.4`。
- `--iter <int>`：拉普拉斯插值迭代求解步数（默认 `300`）。通常无需调整。

### 5.3 构建与游戏内验证
生成完成后，在项目根目录下编译验证：
```bash
./gradlew build -x test
```

可在游戏内安装 Athena 或 Fusion 模组，铺设大面积（如 5x5 以上）地板、电梯与激光连接器混铺测试，检查接缝处是否平整自然。纯净客户端不安装任何 CTM 模组时亦可正常渲染独立单体材质。
